# Outdoor Vacationz

Curated travel and tour booking platform.

## Getting Started

```bash
# Install
npm --prefix client install
npm --prefix server install

# Run frontend (http://localhost:5173)
npm run dev

# Run backend API
npm run server

# Build frontend
npm run build
```

## Structure

- `client/` — React frontend (Vite, TypeScript, Vanilla CSS)
- `server/` — Express backend API
